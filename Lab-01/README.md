
# Lab 01 – Introduction to Power BI

## Overview
An introductory lab focused on exploring the Power BI Desktop interface and building an interactive sales dashboard using sample sales data.

## Activities
- Imported data from Excel and transformed it using Power Query.
- Created column charts, pie charts, and card visualizations.
- Added a DAX measure to calculate total profit.
- Explored interactive filtering between visualizations.
