
# Power BI Lab Exercises

A collection of Power BI lab exercises and in-class activities completed as part of the Business Intelligence with Power BI module at the University of Kelaniya.

## Topics Covered
- Data loading, cleaning, and transformation using Power Query.
- Data modeling, relationships, and star schema design.
- DAX measures and calculated columns.
- Interactive dashboards, data visualization, and filtering.
- Business intelligence, KPI analysis, and forecasting.

## Exercises

| Exercise | Description |
|---|---|
| Lab 01 – Introduction to Power BI | Basic visualizations, interactive filtering, and DAX measures. |
| Lab 02 – Data Loading and Transformation | Data importing, cleaning, and transformation using Power Query. |
| Lab 03 – Data Modeling and Visualization | Relationships, date tables, DAX measures, and analytical visuals. |
| Lab 04 – Dashboard Design and Advanced Visualization | Interactive dashboards, hierarchies, conditional formatting, and revenue analysis. |
| In-Class Activity – Food Waste Monitoring Dashboard | Four-page dashboard covering waste analysis, root causes, profit impact, and forecasting. |

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- Excel and CSV datasets

Each exercise folder contains the Power BI report (`.pbix`), a dashboard screenshot, and an individual README describing the work completed.
