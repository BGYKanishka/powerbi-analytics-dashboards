
# Lab 02 – Data Loading and Transformation

## Overview
This lab focuses on importing data from multiple sources and preparing it for analysis using Power BI and Power Query Editor.

## Activities
- Imported data from CSV and Excel files.
- Combined data from multiple files and sources.
- Cleaned and transformed data by changing data types, renaming columns, filling missing values, and removing unwanted rows.
- Split columns, extracted values, and transposed data.
- Appended queries and created conditional columns to consolidate sales data.
