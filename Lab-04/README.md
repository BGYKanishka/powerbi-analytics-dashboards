
# Lab 04 – Dashboard Design and Advanced Visualization

## Overview
This lab focuses on designing interactive Power BI reports to analyze manufacturer revenue, compare performance across countries, and identify sales trends.

## Activities
- Created interactive dashboards using treemaps, slicers, and combination charts.
- Configured visual interactions, filters, and drill-down hierarchies.
- Created date and product hierarchies to support time-based and detailed analysis.
- Developed DAX measures to calculate previous-year sales and revenue growth.
- Used matrix visualizations, conditional formatting, and gauge charts to present key performance indicators.
- Applied report themes, backgrounds, and layout formatting to improve dashboard usability.
