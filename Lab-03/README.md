
# Lab 03 – Data Modeling and Visualization

## Overview
This lab focuses on designing data models in Power BI, establishing relationships between tables, and creating meaningful visualizations to support data analysis.

## Activities
- Examined data models and relationships between tables, including many-to-many relationship limitations.
- Created calculated columns to establish appropriate relationships between datasets.
- Developed DAX measures and Card visualizations to display key metrics.
- Created a date dimension table and linked it to sales data.
- Applied filters, legends, sorting, and Top 5 analysis to explore revenue performance.
- Customized chart formatting, labels, and colors to improve data presentation.
